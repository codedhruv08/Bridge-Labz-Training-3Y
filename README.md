# BridgeLabz Training - 3rd Year

Welcome to my **BridgeLabz Training** repository! This repository contains my practice exercises, assignments, and foundational web development work completed during the training program.

## 📂 Repository Structure

Here is an overview of the folders currently included in this repository (branch: `html-practise`):

- **`introduction-to-web/ Assignment`** – Core concepts of how the web works and introductory web development assignments.
- **`html-basics`** – Fundamental HTML tags, document structure, headings, paragraphs, links, and lists.
- **`block-inline-elements`** – Practice examples demonstrating the difference and behavior of HTML block-level and inline elements.
- **`iframes`** – Exercises covering embedding external web pages and content using HTML `<iframe>` tags.

## 🛠️ Technologies Used

- **HTML5**
- **Git & GitHub** (Version Control)
- **VS Code** (Code Editor)

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate to the project folder:**
   ```bash
   cd Bridge-Labz-Training-3Y
   ```
3. **Open the files:**
   Open the folder in **VS Code** and launch any `.html` file directly in your web browser (or use the **Live Server** extension in VS Code).
