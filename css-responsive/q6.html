Responsive CSS Cheat Sheet

Filters

CSS visual effects like blur(), grayscale(), and sepia() applied to elements or images.

Media Queries

Rules that apply styles conditionally based on viewport width, e.g. @media (max-width: 600px).

Responsive Design

An approach where layouts adapt fluidly to different screen sizes and devices.

Typography

Scalable text sizing using relative units like rem, vw, and the clamp() function.

Flexbox

A one-dimensional layout model for aligning items in rows or columns.

Grid

A two-dimensional layout system for arranging content in rows and columns.
