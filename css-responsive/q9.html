Core Principles of Responsive Design

Fluid Layouts

Layouts sized using relative units so content resizes with the viewport.

.container { width: 100%; max-width: 1200px; }

Flexible Media

Images and media scale to fit their container without overflowing.

img { max-width: 100%; height: auto; }

Breakpoints

Specific viewport widths where the layout adapts using media queries.

@media (max-width: 600px) { ... }
